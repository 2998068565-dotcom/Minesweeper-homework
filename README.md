# 扫雷（Minesweeper）

C 语言课程练习：控制台版 9×9 扫雷，用 Visual Studio 编写。

## 文件

| 文件 | 作用 |
| --- | --- |
| `扫雷game.h` | 常量与函数声明（`ROW`/`COL`/`ROWS`/`COLS`/`NUM_MINE`/`WIN`） |
| `扫雷game.c` | 游戏逻辑：菜单、初始化、布雷、展开、判胜、输入处理 |
| `扫雷test.c` | 入口 `main`：菜单循环，启动一局 |

## 玩法

- 棋盘 9×9，共 10 颗雷；内部用 11×11 数组留出一圈边界，判雷时不必额外判断越界。
- 输入 `x y +` 表示在 `(x, y)` 标记一颗雷，`x y -` 表示翻开该格。
- 翻到雷即失败，会打印出完整雷区。
- 翻开全部 71 个安全格，或把 10 颗雷全部标记正确，即胜利。

## 实现要点

- `init` 用同一个函数把两个数组分别填成 `'0'`（雷区）和 `'*'`（显示区）。
- `setmine` 在 9×9 范围内随机撒 10 颗雷，重复位置会重试。
- `expand` 递归展开：某格周围 8 格都没有雷时，继续向四周展开。
- `Pwin` 检查标记数是否正确，`cutting` 统计已翻开的格子数，共同决定游戏是否结束。

## 编译运行

```bat
cl 扫雷game.c 扫雷test.c
扫雷test.exe
```

头文件里已定义 `_CRT_SECURE_NO_WARNINGS`，用 MSVC 编译不需要额外参数。

源码是 **GBK（代码页 936）** 编码，MSVC 直接编译正常；用 gcc/MinGW 建议加 `-fexec-charset=GBK` 或先转成 UTF-8，否则控制台中文可能乱码。
